## Translation Approach

### Word Order
Thai is an SVO language. For interlinear translation, preserve the Hebrew source word order as much as possible, translating each word in place. Thai readers will follow the original structure.

### Construct Chains (Semichut)
Hebrew construct chains (noun-of-noun) are preserved in order:
- דְּבַר יְהוָה → คำ–ของ–พระยาห์เวห์ (word-of-YHWH)

### Verbal System
Hebrew verb forms mapped to Thai:
- Qal perfect → past tense (กริยาอดีต)
- Qal imperfect → future/habitual
- Qal imperative → command form
- Niphal → passive
- Hiphil → causative
- Piel → intensive
