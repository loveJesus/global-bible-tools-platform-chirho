## Special Notes for OT Translation
The OT source text is Biblical Hebrew. The glosses translate Biblical Hebrew into **Modern Hebrew** equivalents. This is valuable as a study aid since many Biblical Hebrew words/forms are archaic. For words that are identical in Modern Hebrew, use the same word. For archaic forms, provide the Modern Hebrew equivalent.

## General Rules

### OT Hebrew-to-Modern-Hebrew Glosses

|----------------|---------------|-------|
| יהוה (YHWH) | יהוה | Keep as-is (divine name) |
| אלהים | אלוהים | Modern spelling |
| נַעַר | נער | Youth/lad |
| הִנֵּה | הנה | Behold (keep as-is, still used) |

### Particles (hyphenated with n-dash)
- ה–שמים (the-heavens)
- ב–ראשית (in-beginning)
- ל–אדם (to-Adam)
- מ–ן–ה–ארץ (from-the-land)
- ו–את (and-[object marker])

### Prefixed Particles
Biblical Hebrew uses prefixed prepositions (ב, ל, כ, מ) and the conjunction ו and article ה.
These should be hyphenated with n-dash when glossing:
- בְּ → ב– (in-)
- לְ → ל– (to-)
- כְּ → כ– (as/like-)
- מִן → מ– or מן– (from-)
- וְ → ו– (and-)
- הַ → ה– (the-)

## Translator Notes
- For Biblical Hebrew words still in use in Modern Hebrew, keep the same word
- For archaic words, provide the Modern Hebrew equivalent
- Maintain Hebrew right-to-left text direction
- The object marker את should be glossed as את (it's still used in Modern Hebrew)
